PARTE 2 - CLASSES EM JAVASCRIPT
-------------------------------
Uma classe e um modelo para criar objetos. O constructor prepara o objeto quando usamos new.

Exemplo:
class Pessoa {
    constructor(nome, idade) {
        this.nome = nome;
        this.idade = idade;
    }

    apresentar() {
        return "Meu nome e " + this.nome;
    }
}

const pessoa1 = new Pessoa("Ana", 18);
console.log(pessoa1.apresentar()); // Meu nome e Ana

Conceitos:
- class Pessoa: declara uma classe.
- constructor(...): executa ao criar um objeto com new.
- this: refere-se ao objeto atual.
- this.nome = nome: guarda o parametro no objeto.
- new Pessoa(...): cria uma instancia/objeto.
- apresentar(): metodo da classe.
- return: devolve um valor.

Atributos privados:
class Conta {
    #saldo;

    constructor(saldoInicial) {
        this.#saldo = saldoInicial;
    }

    consultarSaldo() {
        return this.#saldo;
    }
}
const conta = new Conta(100);
console.log(conta.consultarSaldo()); // 100
// conta.#saldo daria erro fora da classe: o atributo e privado.

Heranca (se tiver sido estudada):
class Animal {
    falar() {
        return "Som";
    }
}
class Cachorro extends Animal {
    latir() {
        return "Au au";
    }
}
const cachorro = new Cachorro();
console.log(cachorro.falar()); // Som
console.log(cachorro.latir()); // Au au

PARTE 3 - TRATAMENTO DE EXCECOES
--------------------------------
Excecao e um erro/situacao inesperada que pode acontecer durante a execucao. try/catch permite tratar o erro sem deixar a execucao falhar sem explicacao.

Estrutura:
try {
    // codigo que pode gerar erro
} catch (erro) {
    // o que fazer se houver erro
}

Exemplo:
try {
    let resultado = 10 / 0;
    console.log(resultado);
} catch (erro) {
    console.log("Ocorreu um erro:", erro.message);
}
Observacao: em JavaScript, 10 / 0 resulta em Infinity e nao gera excecao automaticamente.

Exemplo real com throw:
function dividir(a, b) {
    if (b === 0) {
        throw new Error("Nao e permitido dividir por zero.");
    }
    return a / b;
}

try {
    console.log(dividir(10, 0));
} catch (erro) {
    console.log(erro.message); // Nao e permitido dividir por zero.
}

Palavras importantes:
- try: tenta executar o codigo.
- catch: recebe e trata a excecao.
- throw: lanca uma excecao manualmente.
- new Error("mensagem"): cria um objeto de erro.
- erro.message: acessa a mensagem do erro.
- finally: executa ao final, havendo erro ou nao.

Exemplo com finally:
try {
    console.log("Executando");
} catch (erro) {
    console.log("Erro:", erro.message);
} finally {
    console.log("Este trecho sempre executa");
}

Importante: catch so captura erros que acontecem dentro do try. Se usar throw sem um try/catch apropriado, o erro pode interromper a execucao.

PARTE 4 - A PILHA DA ATIVIDADE
------------------------------
A pilha usa LIFO: Last In, First Out (ultimo que entra, primeiro que sai).

No arquivo pilha.js fornecido pelo professor:
- estaVazia(): retorna true se a pilha estiver vazia.
- tamanho(): quantidade de elementos.
- empilhar(elemento): coloca elemento no topo.
- acessarTopo(): retorna o elemento do topo; lanca Error se a pilha estiver vazia.
- desempilhar(): retira o elemento do topo; lanca Error se estiver vazia.
- limpar(): esvazia a pilha.

ATENCAO: no codigo fornecido, desempilhar() diminui o indice do topo, mas nao retorna o elemento. Por isso, primeiro use acessarTopo() e depois desempilhar().

Exemplo:
const pilha = new Pilha();
pilha.empilhar("A");
pilha.empilhar("B");
console.log(pilha.acessarTopo()); // B
pilha.desempilhar();
console.log(pilha.acessarTopo()); // A

Tratando a excecao da pilha:
try {
    const pilha = new Pilha();
    console.log(pilha.acessarTopo());
} catch (erro) {
    console.log("Erro:", erro.message); // A pilha esta vazia
}

PARTE 5 - PALINDROMOS COM PILHA
-------------------------------
Palindromo: texto que fica igual quando lido ao contrario.
Exemplos: arara, radar, 12421, "Ame o poema" (ignorando espacos).

Logica:
1. Obter o texto.
2. Normalizar: minusculas e remover espacos/pontuacao.
3. Verificar se ficou vazio.
4. Criar pilha.
5. Empilhar cada caractere com for.
6. Desempilhar usando while, formando textoInvertido.
7. Comparar texto original e invertido.
8. Mostrar o resultado.

Exemplo de app.js:
import { Pilha } from "./pilha.js";

const campo = document.getElementById("texto");
const botao = document.getElementById("verificar");
const resultado = document.getElementById("resultado");

botao.addEventListener("click", function () {
    let palavra = campo.value.toLowerCase();
    palavra = palavra.replace(/[^a-z0-9]/g, "");

    if (palavra.length === 0) {
        resultado.textContent = "Digite alguma coisa!";
        return;
    }

    const pilha = new Pilha();

    for (let i = 0; i < palavra.length; i++) {
        pilha.empilhar(palavra[i]);
    }

    let invertida = "";

    while (!pilha.estaVazia()) {
        invertida += pilha.acessarTopo();
        pilha.desempilhar();
    }

    if (palavra === invertida) {
        resultado.textContent = "E um palindromo!";
    } else {
        resultado.textContent = "Nao e um palindromo!";
    }
});

QUESTAO 10 - Para que serve finally?
Resposta:
O bloco finally executa depois do try/catch, independentemente de ocorrer uma excecao.

Exemplo:
try {
    console.log("Inicio");
} catch (erro) {
    console.log(erro.message);
} finally {
    console.log("Fim");
}

QUESTAO 17 - Crie uma funcao que verifica se uma palavra e palindromo usando Pilha.

function verificarPalindromo(texto) {
    const palavra = texto.toLowerCase().replace(/[^a-z0-9]/g, "");

    if (palavra.length === 0) {
        return false;
    }

    const pilha = new Pilha();

    for (let i = 0; i < palavra.length; i++) {
        pilha.empilhar(palavra[i]);
    }

    let invertida = "";

    while (!pilha.estaVazia()) {
        invertida += pilha.acessarTopo();
        pilha.desempilhar();
    }

    return palavra === invertida;
}

console.log(verificarPalindromo("Arara")); // true
console.log(verificarPalindromo("Casa"));  // false

QUESTAO 19 - Qual e a diferenca entre == e ===?
Resposta:
== permite conversoes de tipo em algumas comparacoes. === compara sem converter o tipo e geralmente e preferivel.

Exemplo:
console.log(5 == "5");  // true
console.log(5 === "5"); // false
